# NORTA - タスク管理システム

NORTAは、効率的なタスク管理を実現するモダンなWebアプリケーションです。直感的なUIと豊富な機能で、個人からチームまで幅広く利用できます。

## 🚀 主な機能

### ✨ タスク管理

- **タスクの作成・編集・削除**: 詳細なタスク情報を管理
- **ステータス管理**: 未着手 → 進行中 → 完了の進捗追跡
- **優先度設定**: 高・中・低の3段階で重要度を管理
- **期間設定**: 開始日・終了日によるスケジュール管理
- **担当者・グループ管理**: チーム作業に対応

### 📊 表示方式

- **カード表示**: 視覚的に分かりやすいタスクカード
- **テーブル表示**: データの一覧性に優れた表形式
- **ガントチャート**: タスクの期間を視覚的に表示するガントチャート
- **フィルタリング**: ステータス・優先度による絞り込み
- **ソート機能**: 各項目による並び替え

### 🎨 ユーザーインターフェース

- **ダークテーマ**: 目に優しいダークモード
- **レスポンシブデザイン**: デスクトップ・タブレット・スマートフォン対応
- **直感的な操作**: ワンクリックでタスクの作成・編集
- **アニメーション**: スムーズで心地よいUIアニメーション

## 📦 セットアップ手順

### 必要な環境

- Node.js 18.0以上
- npm または yarn

### インストール

1. **リポジトリのクローン**

```bash
git clone https://github.com/NORTA-project/NORTA.git
cd NORTA
```

1. **依存関係のインストール**

```bash
npm install
```

1. **Firebase設定**

`src/firebaseConfig.ts`にFirebaseの設定を追加してください。

1. **開発サーバーの起動**

```bash
npm run dev
```

1. **ブラウザでアクセス**

`http://localhost:5173`でアプリケーションが起動します。

## 🚀 使用方法

### 基本操作

1. **ホーム画面**: タスクの概要とクイックアクション
1. **サイドバー**: ページ間の移動とタスク作成
1. **タスク一覧**: カード形式でのタスク表示
1. **テーブル表示**: 表形式での詳細データ表示
1. **ガントチャート**: タスクのスケジュールとタイムライン表示

### タスクの作成

1. サイドバーの「＋」ボタンまたは「新しいタスク」ボタンをクリック
1. 必要な情報を入力（タイトルは必須）
1. 「タスクを作成」ボタンで保存

### タスクの編集

1. タスクカードまたはテーブルの「編集」ボタンをクリック
1. 情報を変更
1. 「変更を保存」ボタンで更新

### ガントチャートの使用

1. サイドバーからガントチャートページに移動
1. **表示モード切替**: 月表示・四半期表示を選択可能
1. **タスクバーの表示**: 各タスクの開始日から終了日までの期間を可視化
1. **ステータス別色分け**: 未着手（グレー）・進行中（青）・完了（緑）で表示
1. **タスク編集**: バーをクリックしてタスク編集フォームを起動
